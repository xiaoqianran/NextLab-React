# NextLab React 复刻

参考 labs.openai-next.com，以其自身技术栈重写的实现：**Next.js 15 App Router + React 19 + Tailwind CSS v4**，静态导出（`output: "export"`），由 GitHub Actions 构建并部署到 GitHub Pages。

与抓取式静态复刻（见 xiaoqianran/NextLab）的区别：这一版是活的应用 — 页面由 React 组件渲染，模型详情页与工作台由参数架构驱动。

## 数据来源

- `data/models.json`：450 个模型的参数架构（控件类型、选项、默认值、端点、调用示例），从原站详情页的渲染 DOM 解析
- `data/site.json`：编年史（500 条）、更新（8 组）、状态（325 行）、画廊作品（30）、错误码（32）、Agent 工具（34）
- 设计令牌与字体：原站 CSS 的变量体系（亮/暗双主题）与 107 个字体文件
- 作品大图/视频仍走原站公开地址流式加载（约 300 MB 不进仓库）

## 功能

- 外壳：顶栏、亮/暗主题、⌘K 命令菜单（页面 + 全部模型）、G+字母快捷键、移动菜单、API 密钥本地保存
- 工作台 /play：全部模型可切换，参数表单按所选模型的架构生成，请求预览与 cURL/Python/JavaScript 代码实时派生，运行直连 api.openai-next.com（浏览器持用户自己的密钥），异步任务自动轮询
- 模型详情 /models/[id]：架构驱动的工作台 + 原站调用示例 + 相关模型
- 对比 /compare：最多 4 个模型同提示词并行生成
- 对话 /chat：流式输出、本地历史；Agent /agent：浏览器内规划→执行→汇总；NextDraw /draw：画布 + 参考图生成
- 内容页：画廊与作品、范式（原站亦为空）、更新、编年史（时间线/模型切换+搜索）、状态（可搜可筛）、错误码与详情、文档与 34 个 Agent 工具页、设置、作者页

## 本地运行

```bash
npm ci
npm run dev    # 开发
npm run build  # 静态导出到 out/
```

## 已知取舍

- 静态导出无服务端：Agent 为浏览器内实现，原站的服务端代跑不在范围内；状态页为抓取快照
- 原站详情页本身没有价格表，本站不编造价格
- 生成调用需要使用者自己的 API 密钥（与原站一致，密钥只存本地浏览器）
